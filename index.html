资源嗅探器

自动嗅探当前网页里的视频、音频、图片资源，一键预览、复制与下载。纯本地运行，不上传任何数据。

Tampermonkey / Violentmonkey MIT 开源 零数据上报 v1.0.0

🚀 一键安装

先装好脚本管理器，再点下面的按钮，脚本管理器会弹出安装确认。

安装 media-sniffer.user.js 查看源码
还没装脚本管理器？ Edge 安装 Tampermonkey · 或 Violentmonkey
🎬

视频 / 流媒体

mp4、webm、mkv、ts、m3u8、mpd 等，接口里藏着的播放地址也能挖出来。

🎵

音频

mp3、m4a、flac、aac、ogg、wav 等，支持直接在线试听。

🖼️

图片

jpg、png、webp、gif、svg、avif，含懒加载图与 CSS 背景图，带缩略图预览。

🔍

分类与搜索

实时角标计数，按类型切换、按文件名或链接过滤，批量复制与导出 JSON。

🧩

iframe 汇总

嵌套页面里的资源自动上报到主面板，不会因为跨框架而漏掉。

🔒

隐私优先

无埋点、无远程代码、无数据回传。Shadow DOM 隔离，不干扰原网页样式。

  1. 安装脚本管理器在 Edge 扩展商店安装 Tampermonkey 或 Violentmonkey，并保持启用。
  2. 点上面的「一键安装」确认页里核对权限后点安装，脚本会自动通过仓库更新。
  3. 打开任意含媒体资源的网页播放视频、滚动页面或点开图片，右下角 🎯 角标就会开始跳动。
  4. 点圆钮展开面板或按 Alt + S；Esc 收起。挑好资源后预览、复制或下载。
